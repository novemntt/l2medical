# 수술 동의서 문장 난이도 분류: 한국어 의료 LLM 평가

수술 동의서 문장이 **일반 환자에게 어려운지**를 LLM이 판별할 수 있는지 실험한 프로젝트입니다.
의료 특화 모델 `snuh/hari-q3-8b`와 베이스 모델 `Qwen/Qwen3-8B`를 세 가지 프롬프트로 비교했습니다.

## 실험 설계
- **과제**: 동의서 문장을 `어려움` / `보통`으로 이진 분류
- **데이터**: 라벨링된 수술 동의서 문장 30개 (P3는 few-shot 예시 4개를 뺀 26개)
- **프롬프트**
  - **P1** 기준 없이 판단
  - **P2** 명시적 기준 4가지 제시 (전문용어, 긴 문장, 서술어 생략, 모호한 지시어)
  - **P3** few-shot 예시 4개 제시
- **지표**: 정확도, 정밀도(P), 재현율(R), F1 (`어려움` 기준)

## 결과
| 모델 | 프롬프트 | n | 정확도 | P | R | F1 |
|---|---|---|---|---|---|---|
| Qwen3-8B | P1 | 30 | 0.733 | 0.741 | 0.952 | 0.833 |
| Qwen3-8B | P2 | 30 | 0.467 | 0.857 | 0.286 | 0.429 |
| Qwen3-8B | P3 | 26 | 0.538 | 0.889 | 0.421 | 0.571 |
| **hari-q3-8b** | **P1** | 30 | **0.800** | 0.826 | 0.905 | **0.864** |
| hari-q3-8b | P2 | 30 | 0.400 | 1.000 | 0.143 | 0.250 |
| hari-q3-8b | P3 | 26 | 0.500 | 1.000 | 0.316 | 0.480 |

## 주요 발견
- **기준 없는 프롬프트(P1)에서 hari-q3-8b가 가장 좋은 성능**을 보였습니다.
- 기준이나 예시를 준 프롬프트(P2, P3)에서는 두 모델 모두 성능이 크게 떨어졌습니다.
- 특히 hari-q3-8b는 P2에서 **재현율이 0.143까지 급락**했습니다. 의료 지식이 있는 모델이라 전문용어를 "어렵지 않다"고 보는 경향이 나타난 것으로 해석했습니다. 일반 환자의 관점과 모델의 관점이 어긋난 것입니다.

## 실행 방법
```bash
pip install torch transformers pandas
python run_eval.py --model snuh/hari-q3-8b --prompt P1 --csv consent_labeled_draft.csv
```
- 입력 CSV에는 `id`, `sentence`, `label` 열이 필요합니다.
- 실행하면 `result_<모델>_<프롬프트>.csv`가 생성됩니다.
- 실험 환경: RTX 5090 GPU, bfloat16, greedy decoding

## 파일 구성
```
run_eval.py   # 프롬프트 생성 → 모델 추론 → 출력 파싱 → 지표 계산
summary.csv   # 모델·프롬프트별 결과 요약
results/      # 문장별 예측 결과
```
